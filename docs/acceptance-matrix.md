# Plugmesh MVP 验收矩阵

更新日期：2026-10-22

## 状态定义

- `本地已验证`：实现存在，并由当前仓库中的构建、CTest、Playwright 或 smoke 覆盖。
- `模块已验证`：核心逻辑由 mock 或模块测试覆盖，但没有连接真实外部服务。
- `已实现未联调`：代码和配置入口存在，当前环境没有真实凭据或云资源可验证。
- `部分实现`：主流程存在，但原验收条件仍有缺口。
- `未验证`：当前环境不能给出该平台或生产条件下的结论。

## 生产发布阻塞项
