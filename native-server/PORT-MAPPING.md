# 插件服务器端口映射

端口映射由 `plugmesh-server` 内置管理，不需要单独下载或启动映射程序。

启动并登录本地服务器控制台后，在“端口映射”中刷新目标服务器，填写本地监听端口、目标插件服务器、目标主机和目标端口，即可创建映射。监听地址固定为 `127.0.0.1`；协议标签用于说明流量类型，HTTP、WebSocket 和 SSH 等 TCP 流量均以原始字节双向转发。

首次信任目标服务器时，在映射表单填写目标服务器的本地 UI 登录口令。目标端验证成功后会持久信任源服务器；后续连接无需再次输入。口令轮换后，编辑映射并输入新口令重新授权。口令不会写入映射配置或发送给 Worker；服务器仅在内存中暂存，目标端确认信任后立即清除。

映射配置由服务器保存在本机数据目录，随服务器重启恢复。映射可在控制台中编辑、启动、停止或删除；监听端口冲突会拒绝变更并保留先前配置。
