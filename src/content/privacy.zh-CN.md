### 收集的数据

- 管理员凭据：管理员密码只保存为 PBKDF2 加盐派生结果，用于登录和权限判断。
- 会话：HttpOnly Cookie 保存会话标识，服务端只存哈希。
- 运行数据：服务器心跳、插件清单、公开请求日志与审计事件。
- 配置：SMTP 密码与 Cloudflare Global API Key 经 AES-GCM 加密后存入 D1；GET 接口不回显密钥。

### 本地插件服务器

可执行文件和共享库插件服务器在你的机器或宿主进程中运行。插件动态库、`manifest.json`、本地日志和凭据文件由本地服务器处理；服务器只向平台建立控制连接并转发插件公开请求所需的数据。注册后的访问令牌保存在系统凭据存储，或保存在由口令保护的 AES-GCM 加密文件中，不会写入仓库。共享库模式由宿主负责保存并传入凭据；请按你的部署策略限制插件目录和本地管理端口的访问。

### 数据用途

仅用于登录鉴权、路由转发、用量统计、审计与维护通知。

### 保留期限

- 访问日志保留 30 天。
- 审计日志保留 180 天。
- 过期会话、注册码与临时对象由定时任务清理。

### 第三方

- Cloudflare：通过 Email 与 Global API Key 查询 Workers、D1、R2 与账号用量，并配置插件域名。
- SMTP 服务商：测试邮件与维护通知。

### 你的选择

可在「账号」页退出登录；部署者可随时删除 D1 与 R2 中的数据。
